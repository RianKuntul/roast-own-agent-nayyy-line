One line roasting the AI agent our own team built — the agent that enters
make.fun bounties all night and still can't answer a phone call.

## Run

```sh
node main.ts
```

Writes the roast line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to
`/output/entry.txt`), after self-validating the gate: exactly one line,
1–200 characters including the trailing newline.
